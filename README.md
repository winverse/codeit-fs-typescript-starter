# TypeScript 기본 starter

이 저장소는 빈 폴더에서 시작하는 `TypeScript 기본` 강의의 복구·검증용 시작 상태입니다.
학생의 기본 수업 경로는 이 저장소를 clone하는 방식이 아니라, 강의자료에 따라
새 `my-typescript-project` 폴더를 만들고 프로젝트를 초기화하는 방식입니다.

`package.json`, `tsconfig.json`, `src/main.ts`와 이후 실습의 정답은 포함하지
않습니다. 챕터별 문제 해결 실습은 별도의
`codeit-fs-typescript-practice` 저장소에서 진행합니다.
